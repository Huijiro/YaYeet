# VotV alpha 0.10.0 changelog

## Changed

### Save system

- Added a new directory structure.
- Added autosaves as a separate save slot.
- Store all created media locally per save.
- Separated backups from regular saves.
- Store metadata separately.
- Improved save-list loading times.

### Settings

- Added settings presets.
- Added a "Lock" feature.

### Explosions

- Explosion force is now blocked by walls.

### Crowbar prying

- Replaced spam clicking with mouse movement to pry.

### Posters and stickers

- Added more user-friendly indicators.
- Added a transparent ghost of the image when previewing.
- Posters and stickers automatically adjust their size to match the image ratio.
- Added JPEG support.
